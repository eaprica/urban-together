# 都更共好 Urban Renewal Together 🌱

**從資訊透視，走向公平共好。**

這是一項以公共利益為核心的都市更新 UX 研究計畫，探索如何透過資訊透明、跨角色協作與數位服務設計，協助政府提升行政效率，同時保障地主與居民的權益。

🔗 **研究網站：** https://urban-together.pages.dev

## 專案定位

「都更共好」是由社群交流延伸的開放研究專案，目前仍處於問題探索與需求研究階段。

本專案並非政府官方網站，也不代表任何政府機關、建商或民間企業的正式立場。

網站內的服務流程、角色關係與制度構想，除非另有註明，均屬於待驗證的研究假設。

## 研究目標

- **資訊透明：** 讓地主、居民與相關參與者更容易理解都市更新流程。
- **權益保障：** 關注不同利害關係人的資訊取得、參與及異議權益。
- **行政效率：** 探索如何減少資訊落差、重複溝通與流程障礙。
- **公平協作：** 研究政府、地主、實施者、民間技術服務者與第三方監督機制之間的權責關係。

## 歡迎共同參與

我們歡迎來自政府機關、地主、居民、都市更新實務、法律、金融、資訊技術與 UI/UX 設計等領域的意見。

你可以透過：

- **Issues：** 提出問題、研究案例、建議或需要查證的資訊。
- **Pull Requests：** 提交文字、資料、介面或程式碼的修改建議。

所有修改都會經過討論與審核，再決定是否合併至主要版本。

## 協作原則

1. 尊重不同利害關係人的觀點，不預設單一解決方案。
2. 涉及法規、政策或統計的內容，請盡量附上資料來源。
3. 明確區分已確認事實、研究發現與待驗證假設。
4. 不公開未經授權的個人資料或機密資訊。
5. 正式網站的更新由專案維護者審核與發布。
