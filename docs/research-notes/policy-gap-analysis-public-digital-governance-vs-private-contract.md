# 研究筆記：公辦數位治理構想 vs. 民間自主都更的落差分析

> 擬提交至 `eaprica/urban-together` 的 PR 草稿，對應研究網站「04 研究議題」與「05 制度構想（GOVERNANCE）」章節。
> 依本專案協作原則第3、4點「以證據支持討論，清楚區分事實／研究發現／待驗證假設」撰寫。
> **立場聲明**：本文不代表任何候選人、政黨或政府機關之正式立場，亦不構成對任何候選人政見的背書或評論；僅以公開發表之政見內容作為研究素材，探討「公辦數位治理型都更政策」與「民間自主都更實務」之間可能存在的制度落差，供社群研究參考。

## 研究動機

都市更新政見近年出現一類共同方向：以數位化、演算法化的方式重構政府端的審查、估價與補貼流程（例如 BIM 自動審圖、動態容積補貼、公辦中繼房源池等）。這類構想多數聚焦於**政府行政效率**與**公辦都更案**的制度設計。

本文以 2026 年台北市長選舉中一項公開發表的都市更新政見（以下稱「該政見」，具體內容詳見候選人官方政見網站，本文不重複轉載全文，僅就其公開揭露之機制進行研究性分析）為例，交叉比對一個**民間自主都更（地主與民間建商合建）**案例中實際發生的爭議類型，探討「公辦數位治理構想」對「民間自主都更」場域的適用邊界。

## 研究方法與限制（誠實揭露）

- 比對基礎為**單一民間都更案**（已於另一份 PR 中以去識別化案例研究提交，見「同意書與議事防弊條款對照清單」），**不代表所有民間都更案的普遍現象**。
- 該政見內容之分析僅依據公開發表之政見文字，未查證其後續修法進度、市府內部可行性評估或最終立法版本，**政見本身是否會、或已經落地執行，均屬待驗證事項**。
- 本文目的是提出「研究缺口」，而非評價政見優劣，更非代表本文作者或任何協作者支持或反對特定候選人。

## 分析框架：機制 vs. 場域

多數數位治理型都更政見的核心機制，大致可歸納為四類（下列為一般性歸納，非針對特定政見逐條轉載）：

1. 多元清算選項（例如依不同年齡層需求提供換屋／年金／買斷等選項）
2. 動態財務補貼機制（例如物價指數連動的容積或資金補貼）
3. 行政審查數位化（例如自動化圖面審查、縮短核照天數）
4. 公辦房源統籌調度（例如中繼安置房源池）

這四類機制的共同特徵是：**運作主體與適用場域都是「政府公辦都更」或「政府具公權力介入之案件」**。

## 研究發現：民間自主都更的爭議，多發生在「公權力無法觸及」的私法領域

依既有案例研究（見本專案另一份 PR 之去識別化案例），民間自主都更中最常見的爭議類型包括：

| 爭議類型 | 發生領域 | 公辦數位治理機制是否可觸及 |
|---|---|---|
| 同意書關鍵欄位（分配比率）留白 | 建商與地主私法簽約行為 | 否——政府系統不介入私約簽署內容 |
| 共同負擔明細與提列邏輯不公開 | 建商內部財務揭露意願 | 部分間接——動態補貼機制可降低「因通膨而縮水」的爭議，但無法強制揭露建商主動提高建材規格以墊高可提列費用的行為 |
| 估價報告不具名、公信力不足 | 建商委託估價流程 | 部分間接——公辦估價模型可作參考，但現行法規仍要求私案送件時由法定具名估價師簽證，政府系統無法取代私約協商階段的估價公信力問題 |
| 說明會口頭承諾未寫入正式合約 | 地主與建商私法合意範疇 | 否——屬私法自治，政府無權強制企業將口頭讓利條款入約 |
| 同意書被單一人（如委員會召集人）掌控 | 社區內部治理、而非政府流程 | 部分間接——若全面數位化簽署可提升透明度，但民間建商仍可能繞過系統直接向個別地主收取紙本同意書 |
| 缺乏退場機制（落日條款） | 私法合建契約條款設計 | 否——轄區財務模型（如淨現值轉軌標售）通常以整體基地財務可行性為觸發條件，而非個別住戶的契約退場權 |

**初步研究發現**：公辦數位治理型政見所設計的機制，主要解決的是「政府端行政效率」與「公辦案財務永續性」問題；而民間自主都更中最容易引發地主權益爭議的環節，多數落在「私法契約設計」與「社區內部治理」這兩個公權力傳統上不介入的領域。這形成一個**制度落差**：即便公辦都更機制全面到位，走民間自主路線的社區仍可能面臨相同的資訊不對等問題。

## 待驗證問題（供後續研究／訪談延伸）

1. 此落差是否為個案特例，還是具有普遍性？建議以更多民間都更案例交叉驗證。
2. 地方自治條例是否有空間要求「標準化同意書格式」（例如強制分配比率欄位不得留白），將現行僅靠個案自律的環節轉為制度性要求？
3. 是否可能透過**地方自治條例**（而非僅靠政見中的行政系統建置）要求民間都更案的共同負擔明細達到最低限度之強制揭露？
4. 政見中「多軌清算」等選配概念，是否可轉化為**標準契約範本的建議條款**，供民間自主都更社區參考採用，而不僅限於公辦案？
